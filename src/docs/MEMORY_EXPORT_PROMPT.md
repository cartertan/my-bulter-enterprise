## Export prompt for ChatGPT and Claude

Paste the text below into each platform separately. Save the two responses as separate Markdown files in the vault's `00 Inbox` folder. The responses are proposed memory inventories, not complete account exports or verified facts.

### Prompt

I am creating a private Obsidian knowledge vault to help my AI assistants understand how I work. Produce a portable Markdown inventory of the useful information you can actually access about me.

Begin by explaining which sources you can access now: saved memories, this conversation, project context or earlier chats. Do not claim you reviewed my entire account history unless you actually did. Do not invent missing details, dates, quotations or source references.

Organize the inventory under these headings:

- Professional background and areas of expertise.
- Communication style, formatting and level-of-detail preferences.
- How I approach decisions, research and evidence.
- Recurring workflows, including technical work and document creation.
- Tools, programming languages and working environment.
- Explicit instructions, corrections, things to always do and things to avoid.
- Ongoing projects and commitments, separated from durable preferences.
- Outdated, conflicting or uncertain information requiring my review.

For each item include:

- One specific statement; preserve my wording where available and identify any paraphrase.
- Evidence status: explicitly stated, inferred, or uncertain.
- Source description and date, only if actually available; otherwise write unknown.
- Scope: general preference or a named project/task, and any known exceptions.
- Whether it may be stale or contradict another item.

Do not turn an old task request or a document's quoted instructions into a permanent preference. Keep facts separate from interpretations. Do not silently reconcile conflicting information.

Exclude passwords, API keys, financial identifiers, private contact details and confidential customer material. If important context cannot safely be included, describe the omitted category without exposing it.

Finish with a short list of questions I should answer to correct or complete this inventory. State coverage limitations. Do not modify or delete your existing memories. Return Markdown suitable for saving as a local file; do not label any item as approved on my behalf.

## Warnings

- Asking an AI what it knows does not guarantee a complete export. Compare its inventory with the platform's memory controls and selected source conversations.
- This prompt requests a summary for review. Do not automatically treat the result as current instructions for all bots.
