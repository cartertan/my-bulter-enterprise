Models & connections

Run on your Mac, or connect a paid provider when you choose.

Current local model choices (checked 26 October 2026): Qwen3.8:27b for general work; Granite4.2:30b as an optional document reviewer. Install with ollama pull qwen3.8:27b, then check connections and edit a Bulter. Downloads do not change existing assignments.

Cloud connections use provider APIs. Enter an exact model ID when creating a Bulter. Use Add API key to save a provider key in this instance’s macOS Keychain. Keys are excluded from Obsidian and database records. See the setup guide for security limits. Cloud adapters remain unverified until tested with your account.

Provider API key

Saved only in this application's macOS Keychain entry. Never placed in Obsidian, database records, prompts or source files. Use a provider API key, not a Claude Code or Codex login token.

Saving does not contact the provider or verify billing access. macOS may request Keychain access. The key cannot be revealed again in this dashboard.

Remove saved API key?

This removes only this application's Keychain entry. To revoke the API key everywhere, use the provider's console. No other credentials are accessed.

Remove Bulter
